# VERIDIAN content and pricing research

Research date: **22 July 2026**  
Market: **Romania**  
Display convention: recommended VERIDIAN launch prices are rounded, VAT-inclusive prices in RON.

## Method

VERIDIAN is fictional, so there is no honest way to claim an exact market price for an identical product. The values below position each model against current Romanian motorcycles with similar segment, capacity, power, equipment or use case. Promotional prices can change; this document records the source and observed value used for the decision.

Where a retailer publishes both EUR and RON, the RON value was preferred. Motomus states that its RON prices use the BNR exchange rate plus 1%, so those values can move with the exchange rate.

## Maintenance note

These are launch-positioning values, not an automatic live-price feed. Recheck the linked sources before a public campaign, large inventory import or financing calculation. Preserve prices as integer minor units in the database and display them as VAT-inclusive “from” prices where configuration can change the total.
